Security First

Your money, protected

Every transfer is processed as an atomic database transaction — funds are never lost or duplicated, even if something goes wrong mid-transfer.

🔐
Hashed passwords

Credentials are stored as bcrypt hashes — never in plain text, never recoverable.

⚛️
Atomic transfers

Debit and credit happen in one DB transaction with row locks. It either fully completes or fully rolls back.

🕵️
Full audit trail

Every movement of money gets a unique reference ID and a post-transaction balance snapshot.

🚫
Private data layer

MySQL runs inside a private VNet — no public endpoint, reachable only from the cluster.

🧱
Internal-only API

The backend is a ClusterIP service. The internet never talks to it directly.

🔔
Instant alerts

Debit and credit notifications are generated the moment a transaction settles.

About This Project

Multi-Cloud DevOps Training — by Veera Sir, NareshIT

Veera_NareshIT_Bank is a hands-on microservices banking application built as part of the Multi-Cloud DevOps program conducted by Veera Sir at NareshIT. It demonstrates a real-world, production-style architecture — containerized frontend and backend services, a MySQL data layer, Kubernetes deployment on Azure AKS, Infrastructure as Code with Terraform, and automated CI/CD pipelines via GitHub Actions.

Node.js / Express MySQL Docker Kubernetes (AKS) Terraform Azure Cloud GitHub Actions CI/CD NGINX Ingress
